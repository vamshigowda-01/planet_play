Solar System Explorer
An interactive Solar System Explorer built with only HTML, CSS, and JavaScript. It lets users select planets and view animated planet visuals, basic stats, descriptions, distances, and major moons.

Features
Interactive planet selector
CSS-only planet visuals
Animated floating planet display
Planet facts and descriptions
Moon list for planets with known moons
Responsive dark space-themed UI
No frameworks required

Technologies Used
HTML
CSS
JavaScript
Google Fonts

How To Use
Download or clone this repository.
Open index.html in your browser.
Click any planet name in the sidebar to explore it.
Deploy With GitHub Pages
Go to your repository on GitHub.
Open Settings.
Go to Pages.
Under Build and deployment, select:
Source: Deploy from a branch
Branch: main
Folder: /root
Click Save.
Your site will be available at:

https://your-username.github.io/your-repository-name/
